Calculator Testing

This repository contains a simple calculator project created to practice Git and GitHub workflows as part of a Software Engineering lab.

Purpose

The project was used to demonstrate:

* Git repository initialization
* Branch creation and management
* Committing and pushing changes
* Branch merging
* Merge conflict resolution
* Forking and Pull Requests
* Collaborative development using GitHub

Project Structure

* calculator_first5.js – First five calculator functions
* last5.js – Remaining calculator functions
* Calculator_frontend/ – React-based frontend for the calculator

Team Workflow

Each team member worked on a separate feature branch. After completing their assigned tasks, the branches were pushed to GitHub and merged into the main branch using Git.

Note

This project was developed for educational purposes to practice version control and team collaboration using Git and GitHub.
